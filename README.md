# Jornada de Estudos em Python

Bem-vindo ao meu repositório de estudos de programação em Python! 

Este espaço foi criado para registrar minha evolução prática, desde a lógica de programação até conceitos avançados de desenvolvimento de software e inteligência artificial.

## Objetivo
* Construir uma base sólida de sintaxe e lógica de programação.
* Desenvolver autonomia na resolução de problemas computacionais.
* Registrar exercícios diários, testes de código e pequenos projetos práticos.

## Conteúdo do Repositório
* `01-Variáveies-python`: Alguns tipos de variáveis em python.
* `02-Estruturas Condicionais` aprendendo sobre o if, elif e else.

## Tecnologias & Ferramentas
* **Linguagem:** Python 3.x
* **IDE:** Visual Studio Code
* **Controle de Versão:** Git e GitHub
